# Registre des sources et des hypothèses

- **Date de consultation** : 4 novembre 2026, pour toutes les sources.
- **Accès au web** : la politique réseau de l’environnement n’autorisait pas l’ouverture directe des pages ; seul claude.com a pu être lu. Les recherches sont passées par le moteur de recherche, qui renvoie des extraits avec leur URL.
- **Étiquettes** :
  - `[FAIT — extrait]` : chiffre lu dans un extrait de recherche, page non ouverte.
  - `[FAIT — page lue]` : page ouverte et lue.
  - Un chiffre recoupé par au moins 2 sources indépendantes est noté « recoupé ».
- **Requêtes bloquées** :
  - API officielle Annuaire des Entreprises (`recherche-entreprises.api.gouv.fr`) : refusée par la politique réseau, donc aucun comptage SIRENE direct n’a été possible.
  - 30 pages officielles (service-public.fr, urssaf.fr, sites d’éditeurs, pages tarifs) : refusées aussi.
